# Lumina - Museo de las artes

## De qué trata
**Lumina - Museo de las artes** es un museo virtual con 5 salas temáticas: Música pop, Arte, Cine, Moda y Redes y cultura digital. Cada integrante da vida a una sala, y juntas forman un recorrido con identidad propia.

## Objetivo
Desarrollar un sitio web colaborativo usando Git y GitHub, aplicando liderazgo, trabajo en equipo y planificación, y dejando evidencia del aporte de cada integrante mediante ramas, commits y pull requests.

## Qué contiene
- **Música pop:** artistas, géneros y grandes momentos de la música actual.
- **Arte:** arte pop y urbano, ilustración y diseño.
- **Cine:** películas y series que marcaron una época.
- **Moda:** tendencias, íconos y estilos.
- **Redes y cultura digital:** internet, tendencias y creadores.

Cada sala tiene entre 4 y 5 piezas, y cada pieza lleva una imagen, un título y una descripción corta.
